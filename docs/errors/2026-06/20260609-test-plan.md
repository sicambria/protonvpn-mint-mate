## 1. Parsing Functions

### 1.1 `parse_status()`
| # | Scenario | Input | Expected |
|---|----------|-------|----------|
| 1 | Disconnected | `Status: Disconnected` | `("disconnected", ...)` |
| 2 | Connected with details | `Status: Connected\nServer: CH#12\nLoad: 23%` | `("connected", "Server: CH#12\nLoad: 23%")` |
| 3 | Not signed in | `Error: not signed in` | `("not_signed_in", ...)` |
| 4 | Not authenticated | `Please authenticate first` | `("not_signed_in", ...)` |
| 5 | Empty output | `""` | `("not_signed_in", "")` |
| 6 | Unknown format | `Some random output` | `("unknown", ...)` |
| 7 | Status with trailing spaces | `Status:   Disconnected  ` | `("disconnected", ...)` |
| 8 | Missing "Status:" prefix | `disconnected from server` | `("not_signed_in", ...)` |

### 1.2 `parse_countries()`
| # | Scenario | Input | Expected |
|---|----------|-------|----------|
| 1 | Normal output | Full country list with header | 148 countries parsed |
| 2 | No countries | Header only, empty body | `[]` |
| 3 | Empty string | `""` | `[]` |
| 4 | Malformed lines | Lines without 2-char codes | Skip those lines |
| 5 | Unicode names | `Côte d'Ivoire  CI` | `("CI", "Côte d'Ivoire")` |
| 6 | "Updating..." message in output | `Server list is outdated...` | Skip non-table lines |
